# Evaluating Hybrid Semantic–Lexical Retrieval Using Voyage-law-2 and SPLADE for EU Climate Legal Documents

## Description
This project investigates whether a hybrid retrieval framework combining **Voyage-law-2** semantic embeddings with **SPLADE** sparse lexical expansion outperforms BM25 and dense-only baselines for EU climate law documents. It contributes targeted empirical evidence to the legal information retrieval landscape, with a focus on statute-level retrieval quality, document-level reliability, and computational efficiency.
